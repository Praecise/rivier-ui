# Rivier UI gap audit, 13 November 2026

What the library had on 13 November 2026 (131 items: `npm run ui -- list` at `3391bc2`), compared with the
frontier set of libraries a product team reaches for today. Each gap has its category, the libraries that
cover it elsewhere, and the plan: **build** (here, to `CONVENTIONS.md`) or **out** (out of scope, with the
reason). Nothing that exists is removed or renamed; every change is additive.

Status marks: ✅ built on branch `full-ground-viz-motion-map`, ⏳ planned and not yet built, — out of scope.

## New packages

Each is open source, needs no hosted service and sends nothing anywhere. All installed at their latest
release on 13 November 2026. Packages without their own types are listed in `TYPES` in `scripts/registry.ts`.

| Package                     | Licence      | Why                                                                                     |
| --------------------------- | ------------ | --------------------------------------------------------------------------------------- |
| `d3-array` 3                | ISC          | Bins, quantiles and extents for histogram, box plot, fan chart and density              |
| `d3-hierarchy` 3            | ISC          | Treemap, sunburst and circle-pack layouts                                               |
| `d3-sankey` 0.12            | BSD-3-Clause | Sankey node and link layout                                                             |
| `d3-force` 3                | ISC          | Force layout for the network graph (run to rest before drawing, so no motion is needed) |
| `d3-contour` 4              | ISC          | Density contours                                                                        |
| `d3-delaunay` 6             | ISC          | Nearest-point lookup for pointer reading of scatter, density and map points             |
| `d3-geo` 3                  | ISC          | Map projections, paths, graticule, great-circle routes                                  |
| `@tanstack/react-table` 9   | MIT          | Headless data grid state: sorting, filtering, grouping, pinning, selection, pagination  |
| `@tanstack/react-virtual` 3 | MIT          | Row virtualisation inside the data grid                                                 |
